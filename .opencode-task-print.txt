Create a print stylesheet for the portfolio CV.

FILE: src/styles/print.css

When printing (or print preview), hide everything except the content that should appear on a printed CV:
- Hide: header/nav, footer, particle background, scroll indicator, contact buttons, "Ver más" toggles
- Show: hero (name + label), about/summary, skills, education, projects (but simplified)
- Force dark text on white background for print
- Remove shadows, animations, transitions
- Set body font to system sans-serif for better print rendering

```css
@media print {
  /* Hide non-essential elements */
  header, nav, footer, canvas, 
  .scroll-indicator, .btn-grid, .btn-link,
  .case-study-toggle, .particle-canvas,
  .mobile-background {
    display: none !important;
  }

  /* Reset colors for print */
  body {
    background: white !important;
    color: black !important;
    font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif !important;
    font-size: 11pt !important;
    line-height: 1.4 !important;
  }

  /* Make headings printable */
  h1, h2, h3, h4 {
    color: black !important;
    page-break-after: avoid !important;
  }
  h1 { font-size: 18pt !important; }
  h2 { font-size: 14pt !important; border-left: 3px solid black !important; padding-left: 0.5rem !important; }
  h3 { font-size: 12pt !important; }

  /* Skill badges printable */
  .skill-badge {
    border: 1px solid #ccc !important;
    color: black !important;
    background: white !important;
  }

  /* Project cards printable */
  .project-card {
    border: 1px solid #ccc !important;
    box-shadow: none !important;
    page-break-inside: avoid !important;
  }

  /* Links - show URL in print */
  a[href]:after {
    content: none !important;
  }

  /* Remove decorative elements */
  .skill-dot, .status-dot {
    -webkit-print-color-adjust: exact !important;
    print-color-adjust: exact !important;
  }

  /* Expand all collapsed sections */
  .case-study-content {
    display: block !important;
    max-height: none !important;
  }

  /* Section spacing */
  section {
    padding: 0.5rem 0 !important;
    margin: 0 !important;
  }

  .container {
    max-width: 100% !important;
    padding: 0 1rem !important;
  }
}
```

IMPORT this CSS file in src/styles/main.css by adding:
```css
@import './print.css';
```
at the bottom of the file.

Also add a <link> to this stylesheet in src/layouts/Layout.astro head section:
```html
<link rel="stylesheet" href="/styles/print.css" media="print">
```
Actually, since it's imported via main.css, just the @import is fine. Skip the link tag.
